# 🛠️ Projects

Hands-on projects to solidify your learning.

## Suggested Project Ideas

### Beginner (Phases 1-3)
1. **miniGPT** — Train a character-level GPT on Shakespeare
2. **BPE Tokenizer** — Implement byte-pair encoding from scratch
3. **Attention Visualizer** — Web app showing attention patterns

### Intermediate (Phases 4-5)
4. **Fine-tune a Chatbot** — LoRA fine-tune on custom persona data
5. **Model Quantizer** — Script to GPTQ/GGUF quantize and benchmark
6. **Serving Benchmark** — Compare vLLM vs. llama.cpp throughput

### Advanced (Phases 6-7)
7. **ReAct Agent** — From-scratch agent with tool calling
8. **RAG System** — Retrieval-augmented generation pipeline
9. **Multi-Agent Debate** — Two agents arguing to consensus
10. **MCP Tool Server** — Custom MCP server exposing your own tools

### Research (Phase 8)
11. **Paper Reproduction** — Pick a paper, reproduce its key result
12. **Novel Agent Architecture** — Design and evaluate a new agent pattern
13. **Benchmark Suite** — Evaluate models on custom domain tasks
