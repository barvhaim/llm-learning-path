# 🎓 LLM Learning Path — From Zero to Researcher

A structured, self-paced curriculum for mastering Large Language Models and LLM-based Agents.

**Timeline:** ~5 months (can be shortened to ~3 months with prior DL experience)

## 📋 Curriculum Overview

| Phase | Topic | Duration | Status |
|-------|-------|----------|--------|
| 1 | [Foundations](./phase-1-foundations/) | 2-3 weeks | ⬜ |
| 2 | [Transformers](./phase-2-transformers/) | 2-3 weeks | ⬜ |
| 3 | [Pre-training & Scaling](./phase-3-pretraining/) | 2-3 weeks | ⬜ |
| 4 | [Fine-Tuning & Alignment](./phase-4-finetuning/) | 2-3 weeks | ⬜ |
| 5 | [Inference & Deployment](./phase-5-inference/) | 1-2 weeks | ⬜ |
| 6 | [Prompting & Reasoning](./phase-6-prompting/) | 1-2 weeks | ⬜ |
| 7 | [LLM Agents](./phase-7-agents/) | 2-4 weeks | ⬜ |
| 8 | [Advanced Research](./phase-8-advanced/) | Ongoing | ⬜ |

## 🗺️ How to Use This Repo

1. **Go phase by phase** — each folder has its own README with objectives, readings, and exercises
2. **Check off items** as you complete them (edit the checkboxes in each phase)
3. **Take notes** in the `notes/` folder — one file per phase
4. **Do the exercises** — hands-on work is where the real learning happens
5. **Track papers** you've read in the [reading log](./reading-log.md)

## 📐 Prerequisites

- Python programming (intermediate+)
- Basic linear algebra (vectors, matrices, dot products)
- Basic calculus (derivatives, chain rule)
- Basic probability (distributions, Bayes' theorem)
